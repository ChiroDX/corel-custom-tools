Two Valid Implementation Paths

Recommended for You

Path A — VBA + Local Server

VBA (built-in) + Node.js + OpenAI API
  • No extra tools — VBA is already in CorelDraw
  • You already have 80% of it built
  • Server auto-starts via VBA Shell() command
  • Non-modal UserForm = persistent panel (works!)
  • Easy to maintain and extend
  • Works on any Windows machine with Node.js
  • Not a true "Docker" panel (floats, not docked)
  • Requires Node.js installed on machine
  • VBA HTTP calls are synchronous (UI brief freeze)

Path B — VSTA C# Docker

C# + .NET + Visual Studio 2019 + WPF/WebView2
  • True dockable panel — sits alongside Objects, Properties
  • Rich UI — can embed a full web interface (WebView2)
  • Direct async HTTP calls — no UI freezing
  • No external server needed
  • Professional, polished result
  • Requires Visual Studio 2019 (specific version!)
  • C# knowledge needed
  • Much longer development cycle
  • Compiled DLL — harder to quick-edit
  • High setup friction

Bottom line: Path A is achievable now with what you have. Path B is the "dream" version. Start with Path A, migrate to Path B later once you have a working feature set.
