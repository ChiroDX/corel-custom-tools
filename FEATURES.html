Features

What the panel does today, and what is still only an idea

💡 Where things landed

This started as a brainstorm. Nine tools shipped; the rest are still on the list. The three predicted to matter most — Translation, Font Pairing and Colour Palette from Image — all shipped, and the prediction held up.

The model toggle was called an architectural decision rather than a feature, and that was right: it went in with the provider abstraction, so every text tool got it for free. What did not happen is smart per-endpoint auto-routing — one visible setting turned out to be easier to reason about than invisible rules.

The biggest change from the original plan is where the UI lives. The panel is an Electron app beside CorelDRAW, not a VBA UserForm inside it, and it is organised as stacked sections rather than tabs. It also gained something never planned: a live view of the current selection, which is now the thing the whole workflow hangs off.

Shipped — Text In the panel now
Five tools, all operating on the pushed CorelDRAW selection.
🔤
Grammar Check Text
Spelling and grammar across every run in the selection. Each issue returns the original, a suggestion and an explanation; both are copyable.
"Öffnungzeiten" → "Öffnungszeiten"
→ POST /text/grammar. Empty result means clean, not failure.
📋
Completeness Check Text
Checks the required fields for a document type — menu, business card, flyer, poster, invoice — and reports a score plus what is missing, what is optionally missing, and any notes.
4 of 6 required fields found (67%). Missing: Phone number.
→ The type list is fetched from the server, so the dropdown cannot drift out of sync.
🌍
Translation Text
Translate the selection into any of eleven languages: DE, EN, FR, ES, IT, NL, PL, TR, AR, ZH, VI.
"Hühnerfleisch in Ingwersauce" → "Chicken in ginger sauce"
→ GPT-4o-mini is fast and accurate enough for this.
📐
Price Format Checker Text
Flags inconsistent price formatting across the selection — mixed decimal separators, mixed currency placement, missing symbols.
"9.50€" → "9,50 €"
→ Same issue shape as grammar, so the panel renders both with one component.
🔡
Font Pairing Suggester Font
Type the header font you are already using. Get body fonts that pair with it, each with a reason and a Google Fonts flag.
"Playfair Display" → Lato, Source Sans Pro, Cormorant Garamond
→ Pure text call, and the cheapest tool in the set.
Shipped — Image & Colour In the panel now
Generation always uses DALL-E 3, regardless of the model setting.
🎨
Generate Image Image
DALL-E 3 from a prompt, in square, portrait or landscape. The PNG is saved to the OS temp folder; the panel shows the path and offers "Show file" to reveal it in Explorer.
"Fresh bread on a wooden board" → 1024×1024 PNG
→ Files are named chiroDX_* and swept on server start. The panel allows ~130 s.
🖼️
Colour Palette from Image Colour
Point it at an image file — a client's logo — and get the dominant colours back as hex plus CMYK, each copyable straight into a CorelDRAW swatch.
logo.png → 5 colours with CMYK and a role for each
→ Reads a local file, which is one reason the server stays on loopback.
🌈
Colour Palette Generator Colour
Describe a mood or a cuisine style, get a palette back with names, roles and CMYK values.
"Warm autumn tones, earthy and rustic" → 5 CMYK colours
→ Deliberately the same response shape as the extractor, so one renderer covers both.
Shipped — Workflow Not on the original list
The plumbing that turned a set of tools into something usable day to day.
👁
Live Selection View Workflow
Select objects in CorelDRAW, press Send Selection, and the panel shows them immediately — every shape expandable into paragraphs and runs with font, size, weight and a colour swatch. Pushed over a WebSocket, not polled.
4 shapes · page 1 · pending
→ Answers "what am I about to send?" before any AI call is made.
✓
Apply in CorelDraw Workflow
Triggers the VBA write-back from the panel over COM, so the designer never switches windows. The pending state clears when the result-applied event arrives.
Panel → run-macro.ps1 → GMSManager.RunMacro("ApplyResult")
→ Needs the Ping sub for its liveness probe; without it the panel reads offline forever.
🤖
Model Toggle Architecture
One setting for all text tools. Went in with the provider abstraction rather than being bolted on per-tool, which is exactly why adding a tool costs nothing extra.
GPT-4o mini · GPT-4o · Claude Haiku · Ollama
→ Calls are bounded at 60 s with two retries on 429/5xx.
Still Ideas Not built
No endpoint, no UI. Listed in rough order of how much they would be used.
✏️
In-place Formatting Write-back Workflow
Today "Apply" on a text suggestion copies to the clipboard. Patching the run in place — text, font, size and colour together — is the most valuable missing piece, and the exchange format already carries everything needed.
Apply fix → the run changes on canvas, formatting preserved
→ The hard part is character-level formatting survival, not the transport.
✍️
Dish Description Writer Text
Give it a dish name and a tone, get a 1–2 sentence description ready to place.
"Nem Cuốn, appetizing" → "Delicate rice paper rolls filled with fresh herbs…"
→ Needs a tone/style config before it is more than a prompt.
🔄
Tone Rewriter Text
Rewrite the selection in a different register — more formal, more casual, more concise, more appetizing — with a before/after in the panel.
"Hähnchen mit Gemüse" → "Zart gegrilltes Hähnchen auf knackigem Saisongemüse"
📏
Text Fit Optimizer Text
A text frame is overflowing. Rewrite the content to fit while preserving the key information.
Overflowing frame → trimmed to fit, meaning preserved
→ The serializer already sends bounds, so the input exists.
⚖️
Legal Text Checker Text
EU allergen declaration compliance for menus: are all 14 major allergens correctly labelled, are the mandatory additive declarations present.
Item 14 uses allergen "A" but "A1" (Weizen) is required.
→ Would build on specs/menu-data-model.ts, which already models this.
♿
Contrast Checker Colour
Check whether text colour has sufficient contrast against its background. The serializer already sends per-run RGB and CMYK, so this needs no new AI call at all — just the maths.
White on light yellow: ❌ 1.8:1 (needs 4.5:1)
→ The cheapest remaining idea: pure computation, no model, no cost.
🔍
Font Identifier Font
Point a Vision model at an unfamiliar typeface and get a name or close matches.
"Looks like Trajan Pro or a similar classic serif…"
→ Needs a Vision pipeline plus a shape-to-image export step in VBA.
✂️
Edit Image Image
Was in the original four-tool design and did not ship. Select an image, describe the change, regenerate.
"Make the background white"
→ Dropped because regeneration rarely preserves enough of the original to be useful.
🤖
Auto-Layout from Data Layout
Load a JSON file matching the menu data model; CorelDRAW generates the menu — text frames, tab stops, superscript allergens, price columns.
menu.json → a laid-out menu card
→ The big one, and the reason specs/menu-data-model.ts exists.

Model Toggle — As Implemented

One setting in the panel's Settings section sets the model for every text tool. Image generation always uses DALL-E 3 regardless. Claude and Ollama need their key or daemon configured in ai-server/.env; /health reports which providers are actually available.

💡 Smart auto-routing — designed, not built
The idea was to force cheap tools onto cheap models regardless of the setting:
/text/grammar → always GPT-4o-mini
/text/completeness → always GPT-4o-mini
What is actually implemented: every text endpoint takes an optional model and falls back to gpt-4o-mini. /image/generate ignores the setting entirely and uses DALL-E 3. An unknown model key is rejected, not silently substituted.
It stayed unbuilt on purpose: a setting that visibly does nothing on some tools is worse than a setting that always applies.
