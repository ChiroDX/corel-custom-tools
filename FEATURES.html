Feature Brainstorm

Thinking like a designer who makes menus, flyers, and business cards in CorelDraw every day

💡 Honest take before the list

Font tools and color tools are not too much — they're actually some of the most useful things for a designer's daily workflow. The key is to keep each tool focused and fast: one click, one result. No wizard flows, no multi-step dialogs.

The model toggle is an architectural decision, not a feature — it should be baked in from Phase 2 so every tool benefits from it. Routing cheap tasks to cheap models and hard tasks to smart models is where the cost savings are.

The 3 features I'd personally most want as a menu designer: Translation (constant need for DE/EN), Font Pairing (fastest way to find the second font), and Color Palette from Image (extract the brand colors from a logo in 2 clicks).

Tier 2 — High Value, Add Soon Phase 4
These solve real daily pain points. Straightforward to implement.
🌍
Translation Text
Translate the selected text frame. Pick target language from a dropdown (DE, EN, FR, VI…). Replaces text or shows side-by-side.
"Hühnerfleisch in Ingwersauce" → "Chicken in ginger sauce"
→ GPT-4o-mini is fast & accurate enough. Cost: ~$0.001 per call.
✍️
Dish Description Writer Text
Give it a dish name and a tone (appetizing, short, formal). Returns a 1–2 sentence description ready to place on the menu.
"Nem Cuốn, tone: appetizing" → "Delicate rice paper rolls filled with fresh herbs, shrimp, and vermicelli…"
🎨
Color Palette Generator Color
Describe a mood or cuisine style, get back a 5-color palette with CMYK values ready to use in CorelDraw. One click copies to clipboard or applies to swatches.
"Upscale Vietnamese restaurant, warm evening" → 5 CMYK colors
🔡
Font Pairing Suggester Font
Type in the font you're already using as a header. Get 3 body font suggestions that pair well, with a short reason for each.
"Using Playfair Display for headers" → "Try Lato, Source Sans Pro, or Cormorant Garamond for body"
→ Pure text response. GPT-4o-mini, instant.
📐
Price Format Checker Text
Scans all text on the page and flags inconsistent price formats. Are all prices "9,50 €"? Or mixed with "9.50€", "€ 9,50"? Highlights the outliers.
Found 3 prices using "." instead of "," as decimal separator.
🖼️
Color Palette from Image Color
Select a bitmap on canvas (e.g., a logo). Extract the dominant 4–5 colors and return CMYK values. Instant brand color palette from a client's logo.
Select logo → get brand CMYK palette in one click
→ Server reads the image, uses GPT-4o Vision or color quantization.
Tier 3 — Power Features Phase 5
More complex to build, but very powerful for production workflows.
🔍
Font Identifier Font
Select a text object or bitmap with a font you don't recognize. AI (GPT-4o Vision) analyzes the letterforms and suggests what font it is or what fonts look similar.
"This looks like Trajan Pro or a similar classic serif…"
→ GPT-4o Vision. Export text as image → Vision analyzes it.
♿
Contrast Checker Color
Select a text object. Check if the text color has sufficient contrast against its background (WCAG AA/AAA). Essential for accessibility compliance on printed material.
White on light yellow: ❌ Contrast ratio 1.8:1 (needs 4.5:1)
🔄
Tone Rewriter Text
Rewrite the selected text in a different register. Options: More formal, More casual, More concise, More appetizing. Shows a before/after in the panel.
"Hähnchen mit Gemüse" → "Zart gegrilltes Hähnchen auf knackigem Saisongemüse"
📏
Text Fit Optimizer Text
Text frame is overflowing. AI rewrites the content to fit the available space while preserving the key information. "Shorten this description by 30%."
Overflowing text frame → AI trims to fit, preserves meaning
⚖️
Legal Text Checker Text
For menus specifically: checks EU allergen declaration compliance. Are all 14 major allergens correctly labeled? Are the mandatory additive declarations present?
Item 14 uses allergen "A" but "A1" (Weizen) is more specific and required.
→ Uses specs/menu-data-model.ts as reference.
🤖
Auto-Layout from Data Layout
Future big feature. Load a JSON file matching the menu data model, CorelDraw auto-generates the menu with correct text frames, tab stops, superscript allergens, and price columns.
menu.json → fully laid out menu card in CorelDraw
→ This is where specs/menu-data-model.ts becomes essential.

AI Model Toggle — Build Into Architecture From Day 1

The model toggle should be a setting in the panel, not a per-tool option. It sets the default model for all calls. The server can still override per-endpoint for tasks that require specific capabilities (e.g., image generation always uses DALL-E 3 regardless of setting).
