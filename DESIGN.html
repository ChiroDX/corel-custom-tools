1

Server Status Indicator

Shows green/red whether the Node.js AI server is reachable. On open, VBA auto-starts the server in the background using Shell(). If it fails, user sees an error here.

2

Grammar Check

Reads the currently selected text object from the canvas. Sends it to /text/grammar. Results appear below with per-issue Apply Fix buttons.

3

Document Type Dropdown

Sets the context for the completeness check. Options: Menu, Business Card, Flyer, Poster, Invoice. Each has its own required-fields definition in the server.

4

Prompt Box (shared)

Used by both image tools. For Generate: a creation prompt. For Edit: a description of the change to make to the selected image.

5

Results Panel

Each result is color-coded: 🔴 Grammar errors, 🟡 Missing fields, 🔵 Info/suggestions. "Apply Fix" for grammar patches the text directly on canvas. There's no auto-apply — you stay in control.

Data Flow

CorelDraw Canvas
  • Selected text object
  • All text on page
  • Selected image (bitmap)
  • User's prompt text
  • Document type choice
→ VBA XMLHTTP localhost:3000
ai-server (Node.js)
  • Validates request
  • Builds AI prompt
  • Calls OpenAI API
  • Parses JSON response
  • Returns structured data
  • Downloads DALL-E image
  • Saves image to temp path
→ Structured JSON + image path
VBA (back in Corel)
  • Parse JSON response
  • Show issues in panel
  • "Apply Fix" patches text
  • Import image to canvas
  • Replace selected image
  • Update status indicator

Server API Contract

Method Endpoint Request Body Response Notes
GET /health — { status: "ok", version: "1.0" } VBA polls this on panel open to show server status dot.
POST /text/grammar { text: "..." } { issues: [{ original, suggestion, explanation, lineHint }] } GPT-4o returns structured JSON. Each issue maps to a fix that VBA can apply.
POST /text/completeness { text: "...", documentType: "menu" } { missing: ["phone", "hours"], present: ["address", "prices"] } Server has a required-fields config per doc type. AI checks which are present.
POST /image/generate { prompt: "...", size: "1024x1024" } { localPath: "C:\\Temp\\chiroDX_gen_001.png" } Server calls DALL-E 3, downloads the PNG to a temp folder, returns the Windows path. VBA imports it into CorelDraw.
POST /image/edit { imagePath: "C:\\...", prompt: "make background white" } { localPath: "C:\\Temp\\chiroDX_edit_001.png" } VBA exports the selected bitmap to a temp path, sends the path. Server reads file, calls GPT-4o Vision + DALL-E for the edit.

Key Technical Challenges

⏳ VBA is Synchronous
VBA's MSXML2.XMLHTTP blocks the UI thread while waiting for the API. An AI call can take 3–10 seconds — CorelDraw freezes.
Use MSXML2.ServerXMLHTTP with a short timeout + a "loading" label update trick, or show a progress indicator before the call.
🖼 Exporting Bitmaps from VBA
To edit an image, VBA needs to export the selected bitmap to disk as a PNG before sending. CorelDraw's VBA API supports this but needs correct export settings.
Use Shape.Export with cdrPNG filter to save to a temp path, then send that path to the server. Server reads from disk.
📦 JSON Parsing in VBA
VBA has no native JSON parser. The server response is JSON, but VBA can't decode it directly without a library or workaround.
Server returns responses in a simplified format that VBA can parse with basic string operations, or use VBA-JSON (a lightweight open source module).
🚀 Auto-starting the Server
The Node.js server needs to be running before any tool call. Requiring the user to manually open a terminal is bad UX.
VBA Shell() starts the server silently on panel open. Panel polls /health every 2 seconds until it responds, then turns the dot green.
✏️ Applying Grammar Fixes
After AI returns a correction, VBA needs to find the exact text string in the CorelDraw text object and replace it — without losing the existing formatting.
Use CorelDraw's FindAndReplaceText or iterate TextRange to find and replace text while preserving character-level formatting (font, size, color).
📐 Image Placement on Canvas
After generating an image, it needs to be imported and positioned sensibly on the canvas — not dumped at 0,0 at full size.
Import with ActiveLayer.Import, then center the result using Shape.SetPosition based on the current viewport center or selected object bounds.
