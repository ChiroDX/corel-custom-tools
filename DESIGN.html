ChiroDX Tools — Design Document

The panel as built · Interaction design · API contracts · What the hard parts turned out to be

The Nine Tools

🔤
Grammar Check
Finds grammar and spelling errors across every text run in the pushed selection. Each issue comes back with the original, a suggestion and a short explanation.
Input: Selection text
Output: Issue list, each copyable
POST /text/grammar Shipped
📋
Completeness Check
Checks the required fields for a document type. The type list is fetched from the server, so the dropdown cannot drift out of sync with the server's config.
Input: Text + documentType
Output: Score, missing, optional, notes
POST /text/completeness Shipped
🌍
Translate Selection
Translates the selection into one of eleven languages — DE, EN, FR, ES, IT, NL, PL, TR, AR, ZH, VI.
Input: Text + targetLanguage
Output: translatedText
POST /text/translate Shipped
📐
Price Format Check
Flags inconsistent price formatting — mixed decimal separators, mixed currency placement, missing symbols. Very specific, and exactly the mistake that survives proofreading.
Input: Selection text
Output: Outliers with a corrected form
POST /text/price-format Shipped
🔡
Font Pairing
Give it the header font you are already using; get body fonts that pair with it, each with a reason and a Google Fonts flag. Uses the same document type as the completeness check.
Input: headerFont + documentType
Output: Suggestions with reasons
POST /text/font-pairing Shipped
🎨
Generate Image
DALL-E 3 from a prompt, in square, portrait or landscape. The PNG is downloaded to the OS temp folder and the panel offers "Show file" to reveal it in Explorer.
Input: prompt + size
Output: localPath, revisedPrompt
POST /image/generate Shipped
🖼️
Extract Colours from Image
Point it at an image file — a client's logo, say — and get the dominant colours back as hex plus CMYK, ready for CorelDRAW swatches.
Input: imagePath
Output: colors[] with hex, cmyk, name, role
POST /image/color-palette Shipped
🌈
Generate Colour Palette
Describe a mood or a cuisine style and get a palette back with the same hex + CMYK shape as the extractor, so both feed one renderer in the panel.
Input: description
Output: colors[] with hex, cmyk, name, role
POST /image/color-palette-generate Shipped
✓
Apply in CorelDraw
Not an AI tool — the write-back. Triggers the VBA ApplyResult sub over COM so the designer never has to switch windows. The panel clears the pending state when the result-applied event arrives.
Input: Active session
Output: Shapes merged into the document
COM · GMSManager.RunMacro Shipped

1

Three status indicators, all clickable

Server (polls /health every 5 s), CorelDraw (COM ping every 10 s), and the WebSocket. Both polls are self-scheduling rather than setInterval, so a slow request cannot pile up a queue — this matters for the COM ping, where each call spawns a PowerShell process. Clicking a status re-checks it immediately.

2

Selection section — the live document view

Populated by the selection-changed WebSocket event, not by polling. Each shape is an expandable card showing paragraphs, runs, font, size, weight and a colour swatch. This is the panel's answer to "what am I about to send?"

3

Document type comes from the server

Fetched from GET /text/document-types once the server is up, with a hard-coded list as the fallback for a cold start. Hard-coding it is how the dropdown originally drifted away from the server config and started producing 400s.

4

Stacked sections, not tabs

An earlier design used tabs. With the panel this narrow, scrolling one column beats hunting for which tab holds a tool. Every section is a <section> with a real heading, so screen readers and keyboard users get the same structure the eye does.

5

One model setting for all text tools

Not per-tool. Image generation always uses DALL-E 3 regardless. Per-endpoint auto-routing was designed but never built — one visible setting proved easier to reason about than invisible routing rules.

6

Results are advisory

Colour-coded by type and announced through an aria-live region. Nothing is ever written to the document automatically — "Apply" on a text fix copies to the clipboard, and only "Apply in CorelDraw" touches the document. The designer stays in control.

Data Flow

CorelDRAW — VBA
  • Serializes the selection
  • Shapes, paragraphs, runs
  • Font, size, bold, italic
  • RGB and CMYK colour
  • Bounds, layer, shape type
  • Tags shapes with a session id
→ POST /corel/push ServerXMLHTTP
ai-server
  • Validates and bounds input
  • Stores the session in memory
  • Broadcasts over WebSocket
  • Builds prompts per tool
  • Routes to the chosen provider
  • Parses the model's JSON
  • Saves images to temp
→ WS selection-changed GET /corel/selection/:id
Electron panel
  • Renders the live selection
  • Runs a tool on demand
  • Shows results, copyable
  • POSTs the result back
  • Triggers ApplyResult over COM
  • Reveals generated files

The loop closes back in VBA: ApplyResult GETs /corel/result/:id, merges the returned shapes by shapeId, then POSTs /corel/result/:id/applied — which broadcasts result-applied and clears the panel's pending state.

Server API Contract

Every response carries ok; a failure adds error. The authoritative types live in specs/shape-format.ts.

Method Endpoint Request Body Response Notes
GET /health — { status, version, models, providers, corelAdapter, endpoints } Version comes from package.json — it used to be duplicated here and had drifted two majors. Reports which provider keys are configured.
GET /text/document-types — { ok, documentTypes: [{ key, label, required, optional }] } The single source of truth for the panel's dropdown.
POST /text/grammar { text, model? } { ok, issues: [{ original, suggestion, explanation }] } An empty issues array means clean, not failure.
POST /text/completeness { text, documentType, model? } { ok, score, missingLabels, optional_missing, notes } An unknown documentType is a 400, not a guess.
POST /text/translate { text, targetLanguage, model? } { ok, translatedText } Eleven languages; the code must be one the server knows.
POST /text/price-format { text, model? } { ok, issues: [{ original, suggestion, explanation }] } Same issue shape as grammar, so the panel renders both identically.
POST /text/font-pairing { headerFont, documentType, model? } { ok, suggestions: [{ font, style, reason, googleFonts }] } Pure text call — the cheapest tool in the set.
POST /image/generate { prompt, size } { ok, localPath, revisedPrompt } Always DALL-E 3. Saved as chiroDX_* in the OS temp folder and swept on server start. The panel allows ~130 s for this call.
POST /image/color-palette { imagePath } { ok, colors: [{ hex, cmyk, name, role }] } Reads a local file — one of the reasons the server stays on loopback.
POST /image/color-palette-generate { description, model? } { ok, colors: [{ hex, cmyk, name, role }] } Same response shape as the extractor, by design.
POST /corel/push ShapeExchange { ok, sessionId } Capped at 500 shapes. Session ids must match [A-Za-z0-9_-]{1,64}.
GET /corel/selection/:sessionId — { ok, session: SessionDetail } Summary plus the full payload. /corel/selection without an id returns just the latest summary.
POST /corel/result { sessionId, shapes } { ok, sessionId } No status field — the server derives it. Only changed shapes need to be sent.
GET /corel/result/:sessionId — { ok, status, shapes } A missing session answers HTTP 200 with ok:false — VBA treats any non-200 as "server unreachable" and would abandon its poll loop.
POST /corel/result/:sessionId/applied — { ok } Broadcasts result-applied, which is what clears the panel's spinner.
WS /corel/events — WsEvent, discriminated on event selection-changed · result-ready · result-applied · session-expired · corel-connected · corel-disconnected. The panel reconnects every 3 s if it drops.

The Hard Parts, And What They Became

⏳ VBA is synchronous
VBA's XMLHTTP blocks CorelDRAW's UI thread while waiting. An AI call can take 3–10 seconds; a DALL-E call far longer.
Solved by moving the UI out of VBA. VBA only pushes a selection and polls for a result — both fast. Every slow call happens in the Electron panel, which is a separate process and never freezes the canvas.
📦 JSON in VBA
VBA has no JSON parser, and the exchange format is deeply nested — shapes containing paragraphs containing runs.
The serializer emits JSON by hand; the deserializer only ever reads back a flat, predictable subset. Response shapes were deliberately kept shallow so string operations suffice, and specs/shape-format.ts is the written contract both sides code against.
🚀 Auto-starting the server
Nothing works until the Node service is up, and asking a designer to open a terminal is not an option.
Two belts. setup.bat registers a Task Scheduler job that starts it hidden on login, and the Electron main process also spawns it on launch. The panel polls /health and shows a red dot until it answers.
🔌 Driving CorelDRAW from outside
Once the designer approves a result in the panel, something has to run the VBA that writes it back — without making them switch windows and press a button.
run-macro.ps1 calls GMSManager.RunMacro over COM. It also needs a liveness probe: an empty Ping sub whose entire contract is returning without error. Before it existed, the panel showed "CorelDraw offline" permanently.
🎯 Matching shapes across the round trip
A shape leaves CorelDRAW, gets processed elsewhere, and comes back. The document may have changed in between.
Every serialized shape gets a stable shapeId written into its name. On the way back, VBA matches on that id and silently skips anything it can no longer find, rather than guessing by position or content.
🔐 Renderer privileges
An Electron panel that can reach the filesystem and the shell is a large attack surface for what is, after all, a text box that talks to an AI.
Sandboxed renderer with context isolation on and node integration off. The preload exposes named wrappers, never ipcRenderer itself, and every argument is validated in the main process: http(s) URLs only, temp-folder chiroDX_* files only, strict identifier patterns for macro names.
🧪 VBA cannot be tested
There is no way to compile or run .bas modules in CI. A broken macro fails silently inside CorelDRAW, often with a modal box the designer has to dismiss.
Not solved — managed. VBA changes are kept small and conservative, the reviewable logic lives in exported .bas files rather than the binary .gms, and anything touching VBA is flagged as unverified until it has been loaded into CorelDRAW by hand.
✏️ Applying a fix in place
Replacing a text run while preserving character-level formatting is the genuinely hard case, and it is still open.
Currently "Apply" on a text suggestion copies to the clipboard for the designer to paste. Per-run write-back — font, size, colour, and text together — is the next planned step, and the exchange format already carries everything it needs.
