# Corel Templates
This repo contains Template files, which can be used in Corel Draw.

# Installation

Clone this code into following folder

C:\Users\<YourUserAccount>\Documents\Corel\Corel Content\Templates

For example
```bash
cd C:\Users\RakkiDI\Documents\Corel\Corel Content\Templates
git clone git@github.com:ChiroDX/CorelTemplates.git
```

# Usage
Click on File -> New From Template -> Choose CorelTemplate has folder -> Select Template
